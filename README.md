# 🌦️ Weather Web App

A responsive weather application that displays real-time weather information for cities using a weather API.

## 📌 Project Overview

The Weather Web App allows users to search for a city and view its current weather conditions, including temperature, humidity, wind speed, and weather description.

The project demonstrates API integration, frontend development, and dynamic data rendering.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Show humidity levels
- 💨 Display wind speed
- ☁️ Show weather conditions and icons
- 📱 Responsive user interface
- ⚠️ Handle invalid city names and API errors

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
- Fetch API

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/amoltathesoftwareengineer/Weather-Web-App.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Weather-Web-App
```

### 3. Configure the Weather API

- Register with a weather API provider.
- Obtain an API key.
- Configure the API key in `script.js` according to the provider's documentation.

**Security:** Do not publish private API keys in a public repository. Use a backend proxy if the provider's key must remain secret.

### 4. Run the Application

Open `index.html` in your browser, or use the VS Code Live Server extension.
